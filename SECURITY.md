# Security policy

## Supported versions

Security fixes target the default branch and currently supported releases. Repository maintainers identify supported release branches in release notes when they differ from the default branch.

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** entry to submit a private report when available. Do not disclose exploit details in a public issue or pull request. If private vulnerability reporting is unavailable, contact the repository's organization owners through an established private channel.

The maintainers will acknowledge a report, assess impact, coordinate a fix, and agree on disclosure timing with the reporter. Avoid sending credentials or customer data in a report.
